# Ashly's Calculator

Ashly's Calculator is a simple calculator application made using Python and Tkinter.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal calculations
- Clear button
- Error handling for invalid calculations
- Simple graphical user interface

## Requirements

- Python 3
- Tkinter

## How to Run

Open the terminal in the project folder and run:

```bash
python3 calculator.py
